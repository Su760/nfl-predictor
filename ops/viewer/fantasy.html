    Definitions, sample rules and limitations

    Inside-5 is included in inside-10 and red-zone counts; do not add these nested counts. Nullified/deleted plays and two-point tries are excluded. Each metric requires complete coverage for its selected games; unknown values are never zero. Target depth includes incompletions, can be negative, and is unavailable when there are no targets.

    Actual points use credited box-score components. Expected points additionally require all opportunity counts, context and scoring outcomes to reconcile to the box score. Lateral-attribution mismatches follow this same rule for every player and season. Missed observations are not replaced by earlier games.
